# ESS — базовый UI-рендер

Fabric / Minecraft **26.3**, Java **25**. GUI render states и RenderPearl, без прямых вызовов OpenGL.

Примеры отображаются в HUD мира только при включённом Render → RenderTest (ЛКМ по карточке в ClickGUI). На первом запуске RenderTest выключен (затем состояние восстанавливается из конфига); при выключении обработчик выходит до расчётов анимации, текста, геометрии и теней. Отдельный экран не открывается, управление игроком не перехватывается. Палитра — голубой и белый.

## API

Координаты и размеры — GUI-пиксели, цвет — **0xAARRGGBB**. Вызывать на этапе `Screen.extractRenderState`, передавая `GuiGraphicsExtractor`:

```java
UiRenderer.rect(g, 20, 20, 100, 70, 0xff000000);
UiRenderer.shadow(g, 140, 20, 220, 90, 28, 18, 0x48000000);
UiRenderer.rounded(g, 140, 20, 220, 90, 28, 0xffffffff);
MsdfFont.UI.draw(g, "Привет, мир!", 160, 36, 20, 0xff111111);
float width = MsdfFont.UI.width("Привет, мир!", 20);
MsdfFont.UI.centered(g, "MSDF", 250, 65, 16, 0xff111111);
```

`rounded`: выпуклые суперэллиптические углы степени 4, приближение continuous corners в стиле iOS; это не точная копия геометрии Apple. Радиус ограничен половиной меньшей стороны. Контур сглаживается полосой покрытия в один физический пиксель.

`shadow` принимает радиус, размытие и цвет; тень всегда центрирована; мягкость задаётся восемью неперекрывающимися кольцами с плавным изменением альфы. Геометрия кешируется по размерам, радиусу и сглаживанию (LRU, не более 128 сеток). Панель и её тень отправляются одним GUI-элементом без дополнительных strata. При перемещении панелей геометрия не пересоздаётся.

MSDF: Noto Sans, 193 глифа (ASCII, кириллица U+0400–045F, длинное тире, маркер). Неизвестные символы заменяются `?`. Поддержаны переносы строк, метрики, advance и kerning из JSON. Аргумент `top` — верх строки по метрикам, `size` — размер em. Шейдер восстанавливает покрытие из медианы RGB и экранных производных; атлас семплируется с линейной фильтрацией. Размер атласа 504×504, distance range 6 px. Ресурсы включены в JAR; сеть при запуске не нужна.

## Сборка

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

JAR: `build/libs/ess-best-1.0.0.jar`. Если Java на Windows сообщает `Unable to establish loopback connection`, задайте существующий временный каталог с ASCII-путём только для текущего терминала, затем повторите сборку:

```powershell
$env:JAVA_TOOL_OPTIONS='-Djdk.net.unixdomain.tmpdir=C:/gtmp -Djava.io.tmpdir=C:/gtmp'
```

## MSDF-атлас

Метаданные хранятся в `assets/ess-best/msdf`, отдельно от ванильных font providers. Лицензия шрифта OFL включена в `assets/ess-best/font/OFL.txt`. Исходники проекта — CC0 (см. LICENSE).


## Градиенты и тени

`Gradient.linear(from, to, Axis.HORIZONTAL / VERTICAL, origin, length)` задаёт направление в локальных GUI-координатах. `Gradient.flow(...)` дополнительно принимает фазу анимации. Оба варианта принимают `UiRenderer.rounded` и `MsdfFont.UI.draw`.

`UiRenderer.panel(..., gradient, Shadow.DENSE)` гарантирует порядок: тень, затем фон. Типы теней: SOFT (широкая мягкая), DENSE (меньше размытие, больше плотность), COMPACT (узкая плотная), GLOW (голубое свечение). Смещения нет. `flowingLine` рисует тонкую горизонтальную полосу с движущимся белым бликом. В `RenderDemoHud` фаза берётся из монотонного времени, независимо от FPS.

## GUI и Sprint

Правый Shift в мире открывает пять панелей: Combat, Movement, Render, Player, Misc. Правый Shift повторно или Escape закрывает GUI. Чёрные панели имеют выпуклое скругление и центрированную чёрную Dense-тень, общей подложки нет. Примеры HUD сохранены.

В Movement есть Sprint и AutoJump. ЛКМ по заголовку карточки включает/выключает модуль, справа анимируется тумблер. При включении модуль подставляет запрос спринта в клавиатурный ввод при движении вперёд без приседания; обычные ограничения Minecraft сохраняются. Выключение прекращает текущий спринт, ручной спринт остаётся доступен. Состояние, настройки и бинды сохраняются между запусками; при первом запуске модули выключены. GUI не ставит мир на паузу.


Открытие и закрытие ClickGUI: 160 мс на панель, задержка 12 мс между панелями, всего 208 мс. Переливающаяся полоса отправляется одним GUI-элементом вместо отдельных элементов на каждый сегмент.



## Настройки в ClickGUI

ПКМ по заголовку раскрывает/сворачивает настройки с анимацией высоты карточки. ЛКМ по заголовку по-прежнему включает модуль. Высота заголовка уменьшена с 38 до 28 GUI-пикселей, тумблер имеет контур, внутренний трек и плавно движущийся белый индикатор.

- BooleanSetting: название и тумблер.
- SliderSetting: название, плавно обновляемое число справа, полоса и перетаскиваемый бегунок снизу. Значение ограничено диапазоном и шагом.
- ModeSettings: раскрывающийся список с одним выбранным пунктом.
- MultiBooleanSettings: раскрывающийся список с несколькими выбранными пунктами, в свёрнутом виде первый пункт и число остальных.

Выбранные пункты белые с векторной галочкой, невыбранные — серые. Галочка рисуется двумя линиями без загрузки дополнительного атласа. Колесо прокручивает длинные настройки и панели категорий. Настройки не перехватывают клики за пределами видимой области.

## Новые модули

Добавлено 10 модулей сверх Sprint и RenderTest:

| Модуль | Категория | Действие |
| --- | --- | --- |
| CustomTime | Render | Фиксирует отображаемое время Overworld, 0–23900; серверные часы продолжают обновляться |
| Gamma | Render | Яркость 0–1 в пределах стандартной настройки игры |
| NoBob | Render | Отключает покачивание камеры при ходьбе |
| AutoJump | Movement | Включает штатный автопрыжок Minecraft |
| AutoRespawn | Player | Возрождение после задержки, не действует в Hardcore |
| Coordinates | Render | Компактный XYZ HUD, настройка фона |
| Watermark | Misc | Надпись ESS / CLIENT |
| FPS | Render | Счётчик FPS |
| Compass | Render | Направление и угол поворота |
| Zoom | Render | Настраиваемый FOV 30–100 |

Gamma, NoBob, AutoJump и Zoom восстанавливают исходные настройки при отключении, выходе из мира и завершении клиента. CustomTime меняет только клиентское представление часов; отключение возвращает актуальное время сервера. HUD-строки обновляются раз в 5 тиков, не форматируются заново каждый кадр.

## Команды через точку

Команды `.`, включая неизвестные, перехватываются локально и не уходят в чат сервера. Введите `.help` для справки.

```text
.modules
.toggle Sprint
.bind Sprint R
.bind Sprint NONE
.config save main
.config load main
.config list
.config delete main
.friend add Steve
.friend remove Steve
.friend list
.friend clear
.macro add sprint F6 .toggle Sprint
.macro add home H /home
.macro add hello J "Привет всем!"
.macro list
.macro remove home
.macro clear
.set Gamma "Яркость" 1
.set Sprint "Мин. еда" 10
.set RenderTest "Палитра" Ice
.set RenderTest "Примеры" "Градиент,Классика"
```

`.cfg` — алиас `.config`. Названия модулей, команд и клавиш нечувствительны к регистру. Имена профилей и макросов: 1–48 латинских букв, цифр, `_`, `-`. Аргументы с пробелами заключайте в двойные кавычки; внутри кавычек поддерживается `\"`.

Макрос с `.` выполняет локальную команду, с `/` — серверную команду, остальной текст отправляет в чат. Срабатывание однократное на нажатие клавиши; при открытом экране/чате и неактивном окне макросы и бинды модулей не выполняются. Клавиша Right Shift зарезервирована GUI по умолчанию, лучше не назначать её макросу.

Друзья хранятся без дубликатов независимо от регистра; проверка для будущих модулей — `ClientData.isFriend(name)`. Боевых модулей, автоматически использующих этот список, пока нет.

## Хранение

`config/ess-best/state.json` содержит включённые модули, настройки, бинды, друзей и макросы. В режиме разработки это `run/config/ess-best/state.json`. Автосохранение проверяет изменения раз в 40 тиков, команды сохраняют изменения сразу, завершение клиента также сохраняет состояние.

Именованные профили `config/ess-best/profiles/<name>.json` содержат модули, настройки и бинды. Загрузка профиля не меняет друзей и макросы. JSON сначала проверяется полностью, затем применяется; запись выполняется через временный файл и атомарную замену. Повреждённый state сохраняется как `state-broken-<timestamp>.json` перед использованием значений по умолчанию.
